# המרחק ביני לביני

חוויה אינטראקטיבית למפגש האינטגרציה של הכשרת המלוות, מחזור ראשון.

## מה יש באתר

- חוויית משתתפת בעברית וב-RTL
- כתיבת הזהות הנוכחית והזהות שהיא בוחרת לקרב
- בחירה מפורשת אם לצרף את המילים למפה הקבוצתית, ללא שם
- מפה קבוצתית שמתעדכנת ממכשירים שונים
- בקר למנחה עם מצבי מפה חיה, עדות משותפת ונחיתה
- צילום נקודה בזמן במכשיר המשתתפת, ללא העלאת התמונה למפה

## מסלולים

- `/` חוויית המשתתפת
- `/wall?room=first-cohort-aug11` המפה הקבוצתית
- `/wall?room=first-cohort-aug11&control=1` בקר למנחה

## פיתוח מקומי

נדרש Node.js בגרסה 22.13 ומעלה.

```bash
npm install
npm run dev
npm run build
```

האתר משתמש ב-D1 לשמירת המילים שנבחרו להצטרף למפה. תמונות המצלמה נוצרות במכשיר המשתתפת ואינן נשמרות בשרת.
